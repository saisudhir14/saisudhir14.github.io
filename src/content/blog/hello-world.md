I learn something new almost every week, and most of it is gone a month later. This blog is my fix for that. When I figure something out, I write it down here.

## Why write it down

If I can't explain a topic in plain words, I don't understand it yet. Writing shows me the gaps.

- I get a searchable record of what I've learned.
- Someone stuck on the same problem might find the answer here.
- Over time it shows what I've worked on.

## What I'll write about

Mostly AI, cloud and software engineering. Posts will be short and practical, with code you can run.

```python
def learn(topic: str) -> str:
    notes = study(topic)
    return write_post(notes)
```

That's it for the first post.
